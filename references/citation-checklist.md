# 31-Point Citation Readiness Checklist

Run through this checklist before publishing any content. Based on Writesonic's Citation Readiness framework.

---

## A. Opening Structure

- [ ] 1. The page's first 1–2 sentences are a direct, clean answer to the core question
- [ ] 2. The first 200 words function as an independent citation (complete answer when read alone)
- [ ] 3. A table of contents with descriptive anchor links is present
- [ ] 4. A Key Takeaways / TL;DR section is above the fold

## B. Topical Completeness

- [ ] 5. The H1 title contains the exact target query/phrase
- [ ] 6. All major subtopics for this subject are covered (check competitor H2s for gaps)
- [ ] 7. Each section answers only one specific question (no topic mixing)
- [ ] 8. All key terms include explicit definitions
- [ ] 9. Specific numbers, statistics, and data points are included (no vague "significant increase")
- [ ] 10. At least 1 comparison table or framework is present

## C. Entity Signals

- [ ] 11. Brand name is used explicitly instead of pronouns ("we", "it", "this")
- [ ] 12. Author byline with name, credentials, and external profile links is present
- [ ] 13. Organization and Person schemas are implemented
- [ ] 14. Brand, product, and feature names are consistent across all platforms

## D. Technical Accessibility

- [ ] 15. robots.txt allows AI search bots (OAI-SearchBot, Claude-SearchBot, PerplexityBot)
- [ ] 16. Cloudflare WAF is not blocking AI search bots
- [ ] 17. sitemap.xml is up to date and includes all important pages
- [ ] 18. Page load speed is satisfactory (indirect impact on AI crawler accessibility)

## E. Content Formatting

- [ ] 19. H2 headings are in question form and match actual user prompts
- [ ] 20. Paragraphs are kept to 2–4 sentences
- [ ] 21. Terminology is used consistently (no multiple expressions for the same concept)
- [ ] 22. Comparison information is structured as tables
- [ ] 23. FAQPage schema is applied to FAQ sections
- [ ] 24. Appropriate page-type schema is applied (Article/Product/etc.)
- [ ] 25. Both published date and last modified date are displayed

## F. Distribution

- [ ] 26. Plan to share on LinkedIn and relevant communities within 48 hours of publishing
- [ ] 27. Plan to secure at least 1 external backlink/mention
- [ ] 28. Plan to repurpose content into other formats (video, carousel, etc.)

## G. Post-Publish Monitoring

- [ ] 29. Schedule for testing brand citation in target prompts exists
- [ ] 30. Quarterly content update schedule (fresh data, new insights) is planned
- [ ] 31. Key insights are distilled into quotable one-liner summaries
